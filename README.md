# Java RDP Client Application

This repository contains a **Java-based Remote Desktop Protocol (RDP) Client Application**. The application enables users to remotely connect to and control Windows/MAC/Linux machines using the RDP protocol. It is built with a focus on simplicity, efficiency, and cross-platform compatibility.

---

## Features

- **Remote Desktop Access**: Seamless connection.
- **Secure Connections**: Authentication and encrypted communication.
- **Multi-Session Support**: Manage multiple RDP sessions simultaneously.
- **Cross-Platform Compatibility**: Runs on any system with Java installed.
